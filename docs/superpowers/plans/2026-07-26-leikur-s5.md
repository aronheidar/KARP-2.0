# RÁS-Leikurinn S5 — Leynileg hlutverk — Útfærsluáætlun

> **For agentic workers:** Inline-keyrsla (executing-plans). Checkbox-skref.

**Goal:** Valfrjáls leikjahamur þar sem hvert lið fær leynilegt, ólíkt umboð (hlutverk); afhjúpað í leikslok.

**Architecture:** Ný hrein `roles.mjs` (safn + derivation). `server.mjs` úthlutar við start (roleMap í config-JSON, engin schema-breyting), skorar per-lið-umboð, felur hlutverk hinna í `/state`, afhjúpar við `ended`. `client.mjs` bætir gátreit + hlutverks-borða + roleMap-töflu + afhjúpun. Grunn-módúlin fimm ósnert.

**Tech:** ESM `.mjs`, isomorphic; Cloudflare Worker (D1 `env.TENGSL`, HMAC). Próf-mynstur `ok(name,cond)`.

## Global Constraints
- Roles OFF (sjálfgefið) = nákvæmlega núverandi hegðun. Engin ný `/state`-svið án `config.roles`.
- Engin D1-schema-breyting: `roleMap` geymt í `leikur_games.config` (JSON).
- ÓSNERT: `game-config.mjs`, `resolve.mjs`, `scoring.mjs`, `chain.mjs`, `analytics.mjs`, `game-validate.mjs`, `engine.mjs`, `web/worker.js`.
- Composite 0–100 → sameiginleg stigatafla sanngjörn.

### Task 1: `roles.mjs` + próf (hrein módúl)

**Files:** Create `src/lib/leikur/roles.mjs`, `src/lib/leikur/roles.test.mjs`

**Produces:** `ROLES`, `mandateForRole(baseMandate, role)`, `assignRoles(teamIds, roles=ROLES)`, `roleById(id, roles=ROLES)`, `revealRoles(roleMap, roles=ROLES)`.

`roles.mjs`:
```js
// Hlutverka-safn RÁS-Leiksins (S5). HREINT — engin env/crypto/D1.
export const ROLES = [
  { id: 'verdbolgu_haukur', label: 'Verðbólgu-haukur', blurb: 'Stöðugt verðlag umfram allt. Verðbólga við 2,5% er heilög.', weights: { verdbolga: 3 } },
  { id: 'vaxtar_stjorn', label: 'Vaxtar-stjórn', blurb: 'Kraftmikill hagvöxtur skiptir mestu; við þolum örlítið meiri verðbólgu.', weights: { hagvoxtur: 3 }, overrides: { verdbolga: { band: 2.0 } } },
  { id: 'fjarmala_vardstjori', label: 'Ríkisfjármála-varðstjóri', blurb: 'Sjálfbær ríkisfjármál. Skuldir mega ekki fara úr böndunum.', weights: { skuldir: 3 }, overrides: { skuldir: { max: 35 } } },
  { id: 'velferdar_sinni', label: 'Atvinnu-/velferðar-sinni', blurb: 'Full atvinna og velferð. Enginn skal skilinn eftir.', weights: { atvinnuleysi: 3 } },
];

export function mandateForRole(baseMandate, role) {
  if (!role) return baseMandate;
  const w = role.weights || {}, ov = role.overrides || {};
  const kpis = baseMandate.kpis.map((k) => ({ ...k, weight: w[k.key] != null ? w[k.key] : 1, ...(ov[k.key] || {}) }));
  return { ...baseMandate, kpis };
}
export function assignRoles(teamIds, roles = ROLES) {
  const map = {}; teamIds.forEach((id, i) => { map[id] = roles[i % roles.length].id; }); return map;
}
export function roleById(id, roles = ROLES) { return roles.find((r) => r.id === id) || null; }
export function revealRoles(roleMap, roles = ROLES) {
  return Object.entries(roleMap || {}).map(([teamId, roleId]) => { const r = roleById(roleId, roles); return { teamId: +teamId, roleId, label: r ? r.label : roleId, blurb: r ? r.blurb : '' }; }).sort((a, b) => a.teamId - b.teamId);
}
```

`roles.test.mjs` (7 próf): (1) allir weights/overrides-lyklar ∈ MANDATE kpi-lyklum; (2) mandateForRole setur weight 3 á verðbólgu f. haukur; (3) vaxtar_stjorn bræðir band 2.0 á verðbólgu + weight 3 á hagvöxt; (4) mandateForRole(base,null)===base; (5) assignRoles round-robin vefst (5 lið/4 hlutverk → id5=roles[0]); (6) revealRoles skilar label/blurb raðað eftir teamId; (7) **score-diff**: `scoreRound(sampleKpis, mandateForRole(MANDATE, ROLES[0])) !== scoreRound(sampleKpis, mandateForRole(MANDATE, ROLES[1]))` með `sampleKpis={verdbolga:4.5,atvinnuleysi:4,skuldir:38,hagvoxtur:2}` (haukur verðbólga 75 vs vaxtar 100 → composites ólík).

Run: `node src/lib/leikur/roles.test.mjs` → allt pass.

### Task 2: `server.mjs` — úthlutun, per-lið-stig, leynd, afhjúpun

**Files:** Modify `src/lib/leikur/server.mjs`, `src/lib/leikur/server.test.mjs`

**Consumes:** Task 1 exports.

**Breytingar:**
1. Import: `import { ROLES, mandateForRole, assignRoles, roleById, revealRoles } from './roles.mjs';`
2. `gameCfg` skilar að auki `roles: !!c.roles, roleMap: c.roleMap || null`.
3. `create`: eftir custom-blokk → `if (cb && cb.roles) config.roles = true;`
4. `control 'start'`: ef `cfg.roles && !cfg.roleMap` → les lið (`SELECT id ... ORDER BY id`), `roleMap = assignRoles(ids, ROLES)`, endur-les config-obj, set `roleMap`, EIN UPDATE `SET config=?, phase=?, current_round=?`. Annars núverandi UPDATE.
5. `resolve`-lykkja: `const tMandate = cfg.roles && cfg.roleMap ? mandateForRole(cfg.mandate, roleById(cfg.roleMap[tm.id])) : cfg.mandate; const sc = scoreRound(kpis, tMandate);`
6. `state`: reikna `outMandate`/`youRole` (lið→eigið hlutverks-umboð). `out.mandate=outMandate`; `if(youRole) out.role=youRole`; fac → `out.roleMap=revealRoles(...)`; ended → `out.rolesReveal=revealRoles(...)`. Eftir analytics: annótera `scorecard[].role` með label ef roles.

Start-blokk:
```js
if (act === 'start') {
  if (cfg.roles && !cfg.roleMap) {
    const teamRows = ((await env.TENGSL.prepare('SELECT id FROM leikur_teams WHERE game_code=? ORDER BY id').bind(code).all().catch(() => ({ results: [] }))).results) || [];
    let cobj = {}; try { cobj = JSON.parse(game.config || '{}'); } catch (e) {}
    cobj.roleMap = assignRoles(teamRows.map((t) => t.id), ROLES);
    await env.TENGSL.prepare('UPDATE leikur_games SET config=?, phase=?, current_round=? WHERE code=?').bind(JSON.stringify(cobj), 'decide', 1, code).run().catch(() => null);
  } else {
    await env.TENGSL.prepare('UPDATE leikur_games SET phase=?, current_round=? WHERE code=?').bind('decide', 1, code).run().catch(() => null);
  }
  return sjson({ ok: true, phase: 'decide', round: 1 });
}
```

State mandate/role (í stað `mandate: cfg.mandate` inni í out):
```js
let outMandate = cfg.mandate, youRole = null;
if (cfg.roles && cfg.roleMap && you && you.role === 'team' && you.code === code) {
  const rl = roleById(cfg.roleMap[you.teamId]);
  if (rl) { outMandate = mandateForRole(cfg.mandate, rl); youRole = { id: rl.id, label: rl.label, blurb: rl.blurb }; }
}
const out = { phase: game.phase, round: game.current_round, code, teams, mandate: outMandate, decisions: DECISIONS, event: game.phase === 'lobby' ? null : ev, results: game.phase === 'resolved' ? roundResults : null, you: you && you.code === code ? { role: you.role, teamId: you.teamId } : null };
if (youRole) out.role = youRole;
if (cfg.roles && cfg.roleMap && you && you.role === 'fac' && you.code === code) out.roleMap = revealRoles(cfg.roleMap, ROLES);
if (cfg.roles && cfg.roleMap && game.phase === 'ended') out.rolesReveal = revealRoles(cfg.roleMap, ROLES);
```
Analytics annótering (eftir `out.analytics = ...`):
```js
if (out.analytics && cfg.roles && cfg.roleMap) {
  const lbl = Object.fromEntries(revealRoles(cfg.roleMap, ROLES).map((r) => [r.teamId, r.label]));
  out.analytics.scorecard.forEach((row) => { row.role = lbl[row.teamId] || null; });
}
```

function roleBanner(st) { return st.role ? '<div class="lk-role-banner">🎭 Þitt umboð: <b>' + esc(st.role.label) + '</b> — ' + esc(st.role.blurb) + '</div>' : ''; }
