# RÁS-Leikurinn „Ísland 2000–2032" — Útfærsluáætlun

> **For agentic workers:** Inline-keyrsla. Stór sjónræn lota (4 verk).

**Goal:** Yfirtöku-skjár + 2000–2032 tímalína (8 kjörtímabil) + söguleg sjálfgefin sviðsmynd + mission-control sjónræn endurhönnun studio-stjórnstöðvar. Markmið sýnileg, leið falin.

## Global Constraints
- Aðeins /leikur/ fær bare-skel. Engin breyting á öðrum síðum.
- Tímalíkan = ENDUR-MERKING (0 breyting á hermunar-dýpt/kvörðun; ROUNDS=8, QUARTERS_PER_ROUND=4 óbreytt).
- ÓSNERT: engine/resolve/scoring/chain/roles/studio/server/analytics/game-validate.
- game-config.test er validation-based → SCENARIO-rewrite verður að hafa 8 atburði, gild sjokk-lyklar, ≥2 viðbrögð m/gildum effect-lyklum.

### Task 1: Skel + tímalíkan + söguleg sviðsmynd

**Files:** `web/src/layouts/Layout.astro`, `web/src/pages/leikur/index.astro`, `src/lib/leikur/game-config.mjs`

1. **Layout bare:** bæta `bare = false` í props; í `.shell`-class: `${wide ? ' shell-wide' : ''}${bare ? ' shell-bare' : ''}`; CSS `.shell-bare { grid-template-columns: 1fr; } .shell-bare .nav, .shell-bare .news { display: none; }`.
2. **index.astro:** `<Layout ... bare={true}>`; `main[data-pg="leikur"]` max-width 980→1440px (og padding minni á breidd).
3. **game-config.mjs:** `export const YEAR_START = 2000;`. Endurskrifa `SCENARIO.events` (8, tafla úr spec; hvert m/`icon?` valfrjálst tákn f. hrun/COVID). Halda 2–3 viðbrögðum per atburð með gildum lever/shock-effect.

Run: `node src/lib/leikur/game-config.test.mjs` → 98 pass (eða uppfært); `node src/lib/leikur/resolve.test.mjs` (SCENARIO-háð) → grænt. Ef resolve-próf reiða sig á gömul atburða-shocks, lagfæra prófin.

### Task 2: Studio-rist + tímalína + ár-ás (client-uppbygging)

**Files:** `src/lib/leikur/client.mjs`, `web/src/pages/leikur/index.astro` (CSS)

Import: `import { scoreRound } from './scoring.mjs';` + `import { YEAR_START } from './game-config.mjs';` (eða les úr studio-const). Hjálp:
```js
const termYears = (r) => [YEAR_START + 4 * (r - 1), YEAR_START + 4 * r];
```
- **stChart ár-ás:** x-merki = ár (`YEAR_START + i`), sýna kjörtímabils-skil.
- **renderStudio endurhönnun:** ný uppbygging —
  - `<div class="lk-ribbon">` 8 kjörtímabil (`term-seg` past/now/future + atburða-tákn).
  - Kjörtímabils-haus (`termYears(st.round)` + event.title + icon + text + sjokk).
  - `<div class="lk-studio-main">` grid: vinstri `#lk-st-chart` (gröf), hægri `.lk-studio-controls` (flipar+sleðar+umboð+læsa, sticky).
- CSS: `.lk-ribbon`, `.term-seg`, `.lk-studio-main` (grid 1fr 380px; @media stafla), `.lk-studio-controls` (sticky), gauge/heatmap-classes (Task 3).

Run: `node --check src/lib/leikur/client.mjs`; astro build.

### Task 3: Gauges — Þjóðarhagur heildar-mælir + markmiðs-mælar + hitakort

**Files:** `src/lib/leikur/client.mjs`, `web/src/pages/leikur/index.astro` (CSS)

Í `drawStudioPreview` (endurskrifað f. nýja uppbyggingu):
- Reikna `previewKpis` (loka-ár hvers mandate-KPI úr sim) → `scoreRound(previewKpis, st.mandate)` → composite + perKpi.
- **`arcGauge(score)`** — SVG hálfhringur 0–100, valens-litur (grænt≥70/gult≥40/rautt), stór tala „Þjóðarhagur".
- **`goalMeter(kpi, value, scoreKpiVal)`** — lárétt: núgildi vs markmið, band-litað, stig/100.
- 4 KPI ár-ás línurit (stChart) + 4 goalMeters + **hitakort** (36 flísar, bakgrunns-litur eftir `dev*polarity` vs BAU).
- Uppfærist við hverja sleða-hreyfingu (debounce óbreytt).

CSS: `.lk-gauge`, `.lk-goalmeter`, `.lk-heat`, `.lk-heat-tile`.

Run: `node --check src/lib/leikur/client.mjs`; astro build.
